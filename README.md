# 图书清单

一个用于记录和整理个人书目名称的简单项目。书目保存在根目录的 `book` 文本文件中，每行一项，便于阅读和维护。

## 当前书目

- 我的世界
- DWCA
- 阿泽杂物
- 悲惨世界
- 阿布布
- 老舍
- 围城

## 项目结构

```text
.
├── book        # 图书名称清单，每行一项
└── README.md   # 项目说明
```

## 使用方式

直接打开根目录下的 `book` 文件查看书目。添加书目时，每行填写一个名称，并使用 UTF-8 编码保存。

欢迎通过 Issue 或 Pull Request 提交书目修正和补充。提交前请保持每行一个条目，并避免重复内容。
